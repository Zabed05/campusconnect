# CampusConnect 🎓

CampusConnect is a full-stack university student platform designed to centralize important campus activities and information in one place.

The platform will allow students, faculty, and administrators to interact with features such as announcements, events, and event registrations.

## 🚀 Project Status

🚧 Currently under active development.

## ✨ Planned Features

- User authentication and authorization
- Role-based access control
- Student, faculty, and admin roles
- Campus announcements
- Event management
- Event registration
- User profiles
